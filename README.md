# MartX – Glassmorphic Shopping Mart 🛒✨

An interactive, responsive e-commerce web application with a glassmorphic design language, live search, dynamic category filtering, Indian Rupee (₹/INR) currency support, cart/wishlist management, and local storage state persistence.

---

## 🚀 Features

- **🛍️ Dynamic Product Catalog**: Dynamically rendered products across multiple categories (Audio, Wearables, Electronics, Gaming, Accessories).
- **🔎 Live Real-Time Search**: Instant search filtering as you type.
- **🏷️ Category Filtering**: Filter items effortlessly with one-click category chips.
- **🛒 Shopping Cart Management**: Add items, increase/decrease quantities, remove items, and calculate subtotals in Indian Rupees (₹).
- **❤️ Wishlist**: Save favorite items to a wishlist drawer and move them to your cart when ready.
- **🌙 Dark / Light Mode**: Seamless theme toggling with persistent state.
- **✨ Glassmorphic UI**: Ultra-modern frosted-glass effect with ambient glowing blobs, backdrop filters, and hover micro-animations.
- **💾 LocalStorage Persistence**: Retains cart items, wishlist items, and theme preferences across page reloads.
- **🔔 Toast Notifications**: Real-time feedback alerts when adding, removing, or checking out.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile viewport sizes.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure and modern markup.
- **CSS3**: Custom CSS Variables, Glassmorphism (`backdrop-filter`), Flexbox & CSS Grid, Keyframe animations.
- **JavaScript (ES6+)**: Vanilla JS DOM manipulation, Array methods, LocalStorage API, and `Intl.NumberFormat` for Indian Rupee (`en-IN`) formatting.
